# Poem Studio 作品编辑

此前用户另给的长幅海报有三人并排、细线框选和底部服装剪影。它作为作品目录的对齐和标注参考，单独记录，不混入上述 Behance 项目署名。

首页封面以用户最新给的棋盘格群像为准。把实物沿外轮廓提取，把界面截到屏幕边缘。所有作品共用一张浅色底纸，洋红报头、蓝色方框和粉色短注贯穿全场。按顺序移动一个选框，作品留在原位。需要演示 App 时，在同一部设备里按操作顺序切换原稿界面，让页名与画面同步。

从用户给的案例截图取样，棋盘用荧光黄绿 `#DBFD00` 与白色，报头用亮粉 `#FF20A7`，说明区用近黑 `#131313`。作品名用蓝底白字，设计细节用粉底白字，小字号用较深的粉保持对比。裁切前对照真实展板版本，在异色底上检查把手孔、衣领、背卡边缘及透明区。选中的作品清晰，周围作品显示方块马赛克，文字始终清楚。站立件的阴影靠近底边，悬浮件与地面阴影留出距离；选框与悬浮件共享位置。参考 [Anthropic 的 frontend-design Skill](https://github.com/anthropics/skills/tree/main/skills/frontend-design) 按内容分配视觉层级，并在真实屏宽下复查效果。

## 排作品

先决定访客按什么找作品。品牌识别、包装和地方视觉放「品牌与包装」，学习 App、健康产品和开源工具 UI 放「网页与应用」，实体产品、工作坊和机械臂放「实物与交互」，以方法和材料为主的绣谱放「非遗与工艺」。一个项目只占一个主分类。原型网页、论文和 Github 链接是案例内的延伸阅读。

首页用于精选、索引和研究入口。把详细展板留给案例页。切换首屏时保持文字和图像的边界稳定，同一作品名不在画面上叠三遍。移动端重新排文图顺序，缩窄时核对英文副标、交互入口和装饰的实际位置。

## 取景和用字

|素材|目录图|详情|
|---|---|---|
|毕业冰箱贴|黑底五款校徽背卡合照，完整保留五款。横框补同色留白。|保留竖幅原图，单件近照解释学位服与证书。|
|碉琢、神湾|碉琢以完整盆器和包装为主景，结构草图作小图。神湾选用参展版完整标志和农业、渔业、旅游业三幅插画。|选取标志来源、图形变化及一个能看清用法的物件。|
|悦绣、MeYou、科研网页|悦绣并列课程和图案详情。MeYou 将包装字段和跨地区对照并置。科研工具各取一张代表性图表。|从使用者的一次具体操作讲起，图注说明该看哪个字段或哪条曲线。|
|纱以生花、名桥、机械臂|纱以生花放大一个分形花形，旁列同谱变体。名桥把可辨认的完整名字与制作过程并排。机械臂保留夹具与布面的关系。|研究项目展示推演，参与式项目展示现场和取件，实体原型展示操作位置和结果。|

同一级目录框采用同一比例和标题基线。取景按图内主体决定，详情用原构图。大面积留白给作品，荧光黄或粉各自承担一个强调位。英文报头用 Display，英文小注用等宽体，中文用同一套无衬线字体，以字号与字重区分标题和正文。

从整份演示稿选图。按缘起、设计过程与应用结果选择 5–10 张不同的图，分章展示，并提供放大和原图入口。每个作品的文案省略作者栏，保留比赛版本、奖项级别和可核实的使用情况。

全站文案按 [Humanizer-zh](https://github.com/op7418/Humanizer-zh) 通读。用可指认的物件、界面或研究动作替换套话，区分入围与获奖。
